# Elevatex EFB - SimBrief Dispatch

Electronic Flight Bag (EFB) web application designed to fetch and display operational flight plan (OFP) data from SimBrief.

## Tech Stack

- React 19
- TypeScript
- Vite
- Lucide React

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
